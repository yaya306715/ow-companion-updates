# ow-companion-updates
ほぼ自分用に作った、OW２用のパークとか情報確認アプリです。

【インストール方法】

1.本サイトの「Releases」から1番バージョンの数字が高い
  OW-Companion-Setup.exeをインストール

2.インストールしたらOW-Companion-Setup.exeアプリケーションを起動

4.不明なアプリとでても問題ないので進行、流れに沿ってインストール

5.インストール後はデスクトップにショートカットが追加されるので
  次回以降ショートカットから起動も可能。

※本ソフトの設定にある、本体ソフトの自動更新をチェックしといてくれると起動時に新しいバージョンが出た場合に自動で更新されます。

不具合・要望があればX(旧twitter)にて@yaya_rdskにご連絡ください。
